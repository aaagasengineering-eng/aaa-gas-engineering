# AAA Gas Engineering — Website

Static site (HTML/CSS/JS). Host on Vercel; domain: aaagasengineering.com

## Structure
- index.html, about.html, gallery.html, contact.html, thank-you.html
- products/  — vaporizer, cylinders, regulators, valves, custom solutions
- cities/    — Gujranwala, Lahore, Karachi, Islamabad, Faisalabad
- blog/      — price guide, how a vaporizer works
- css/ js/ images/ (WebP used on pages; PNG kept only for logo, favicon, social preview)

## Editing notes
- Contact form posts to Web3Forms and redirects to thank-you.html
- After adding a page, add it to sitemap.xml and submit in Google Search Console
- Compress new images (WebP) and always set alt, width and height
